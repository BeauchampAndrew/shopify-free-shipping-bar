# Free Shipping Progress Bar for Shopify

A cart drawer progress bar with up to 4 reward milestones (free shipping, % off, free gift). Thresholds count dollars or items. Updates live as the cart changes. No app.

Built with Claude Code on camera for the BS&Co YouTube channel. Install steps, settings and customization prompts go here once the build is done.
